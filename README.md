# 최근 날씨 확인

기상청 단기예보 조회서비스(공공데이터포털)로 **서울·대전**의 원하는 날짜·시간대 날씨를 보여주는 웹 서비스입니다.

## 실행

Node.js나 Python 없이 Windows 기본 PowerShell만으로 동작합니다.

- `start.cmd`를 더블클릭하면 서버가 켜지고 브라우저가 열립니다.
- 또는 터미널에서 (`weather_service` 폴더 안에서):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1 -Open
```

주소: http://localhost:8080 (끄려면 Ctrl+C)

## 사용 방법

1. 지역(서울/대전)을 고릅니다.
2. 기준 날짜를 고릅니다. (오늘 포함 최근 3일)
3. 기준 날짜로부터 **오늘 / 내일 / 모레** 중 하나를 고릅니다.
4. 시간대(00시~23시)를 고르고 **날씨 확인하기**를 누릅니다.

결과에는 기온, 하늘상태·강수형태, 강수확률, 1시간 강수량, 습도, 바람, 일 최저/최고기온과 그날의 시간대별 예보가 나옵니다. 시간대별 예보 칸을 누르면 그 시각으로 바로 바뀝니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `server.ps1` | 정적 파일 제공 + `/api/forecast` 프록시 (인증키는 서버에만 보관) |
| `public/index.html`, `style.css`, `app.js` | 화면과 조회 로직 |
| `.env` | `KMA_SERVICE_KEY` 인증키 (`.env.example` 참고) |

- 사용 API: `getVilageFcst` (단기예보조회)
- 예보 격자: 서울 (60, 127), 대전 (67, 100)

## 제약 사항

- 기상청 API는 **최근 3일간 발표된 자료만** 제공합니다. 그래서 기준 날짜는 오늘 포함 최근 3일로 제한됩니다.
- 앱은 선택한 시각을 포함하는 가장 최근 발표분(02·05·08·11·14·17·20·23시 발표)을 골라 조회합니다. 가장 오래된 날짜의 00~02시처럼 조회 가능한 발표분이 없는 시각은 안내 메시지가 나옵니다.
- 이미 지난 시각은 실제 관측값이 아니라 당시 발표된 예보값입니다.
